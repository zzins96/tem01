전송 기록

아직 전송 없음
여기에 전송 결과가 순서대로 쌓입니다.
· 실제 사이트는 페이지 이동과 동시에 전송되므로 sendBeacon(실전송 방식)을 씁니다. 이 방식은 브라우저가 응답을 돌려주지 않아, 성공 확인은 구글 시트를 직접 열어 확인해야 합니다.
· 실제 폼에는 뒷번호 4321 입력 시 “이미 상담 중”으로 막히는 테스트 코드가 있어 시트로도 안 넘어갑니다. 연동 테스트는 4321이 아닌 번호로 하세요.
· 데이터가 안 들어오면 대개 (1) /exec URL 오타, (2) 액세스 권한이 “모든 사용자” 아님, (3) 코드 수정 후 재배포 누락 중 하나입니다.
